# CLAUDE.md — полный контекст проекта TBOIAC

Этот файл нужен, чтобы **любая новая сессия Claude (на любом устройстве) могла продолжить работу
без потери контекста**. Здесь всё: кто пользователь и как с ним работать, что за проект, какие
решения уже приняты и почему, архитектура, процесс, подводные камни, история отзывов, что не
проверено и что делать дальше. Прочитай целиком перед первой правкой.

---

## 0. TL;DR для новой сессии

- Проект: **TBOIAC — Isaac Admin Console**, мод-песочница для **The Binding of Isaac: Repentance+**
  (Lua API игры). Цель — дать контент-мейкерам меню, из которого можно сделать с игрой всё
  (предметы, мобы, время, комнаты, правила-«если-то», волны, оверлей для видео).
- Текущая версия: **v0.9.0** (в `main`, PR #1, #2, #3 слиты).
- **В игре мод проверяет только пользователь** (присылает скриншоты). У Claude нет игры: проверка —
  только `./tools/check.sh` (синтаксис + smoke-тест на заглушках API).
- Общение с пользователем — **на русском**. Пользователь ценит: красивый, понятный UI, иконки/спрайты,
  мышь, подсказки; всё «как у нормального меню». Не любит перегруженные текстовые списки.
- **Da Rules** (мод JSG) — идейная основа, но **никакого кода и данных Da Rules в проекте нет и быть
  не должно** — только свои реализации механик (решение пользователя).
- Рабочая ветка: `claude/tboi-rep-content-mod-s1q34p`. PR создаётся/мёржится **только по просьбе
  пользователя** (обычно он пишет «Создай пулл реквест», затем «Смёрджи PR»). После мёржа ветку
  пересоздают от свежего `main` (см. §6).

## 1. Пользователь и стиль работы

- Пишет по-русски, коротко, иногда с опечатками («смёрджи», «пулл реквест», «claude,,nd» = CLAUDE.md).
  Отвечать по-русски, конкретно, без воды. В конце ответа — что сделано, что проверить в игре.
- Роль: делает мод для контент-мейкеров (видео по Isaac). Сам тестирует в игре на REP+, присылает
  скриншоты меню. Использует русификатор (названия предметов в игре на русском).
- Ожидания к UI (из отзывов): меню должно быть **красивым и понятным**: много спрайтов/иконок,
  чёткие пояснения и подсказки, большие кнопки где уместно, управление **мышью**, крестик закрытия,
  меню **по центру**, ровные отступы, ничего не «ломается».
- Просит «сделать всё» списком — выполнять **все пункты**, в ответе пройтись по каждому.
- Предпочитает, чтобы Claude сам принимал разумные решения и не задавал лишних вопросов.
- Репозиторий: `bouquet2025/tboiac` (GitHub). Пользователь попросил сделать его **приватным** —
  у Claude нет инструмента для смены видимости; пользователь делает это сам:
  GitHub → репозиторий → Settings → General → Danger Zone → Change repository visibility → Private.

## 2. Решения, которые уже приняты (не пересматривать без запроса)

1. **Da Rules**: пользователь прислал архив Da Rules от автора (`da_rules_2403871374.zip`, ~225 тыс.
   строк Lua). README Da Rules просит не публиковать моды на его коде и указывать автора при
   использовании данных. Решение пользователя: **механики Da Rules добавляем по-своему, своим кодом,
   чтобы не было претензий**. Код, таблицы данных (названия, пути anm2, EntityConfig-выгрузки),
   формат правил Da Rules — не копировать и не импортировать. Разбор устройства Da Rules своими
   словами — в `docs/DA_RULES_ANALYSIS.md`. Архив в репозиторий не добавлять.
2. Мод работает на **ванильном API REP+**. **REPENTOGON — опционально** (если есть: ImGui-меню,
   названия на языке игры, точные пулы, спрайты всех сущностей). Код всегда должен работать без него.
3. Консольные команды (`Isaac.ExecuteCommand`) — только там, где нет API (варп этажей `stage`,
   `goto`, `restart`, `reseed`). В UI предупреждаем, что это может влиять на достижения.
4. Действия меню выполняются **в `MC_POST_UPDATE`**, не в render (иначе вылеты, напр. от пилюль).
5. Язык UI по умолчанию — русский (`ui.lang = "ru"`), английский — полноценный второй.
6. Все тексты — через i18n-ключи в `scripts/tboiac/core/lang/{ru,en}.lua` (оба файла должны иметь
   одинаковый набор ключей — это проверяет тест).

## 4. Архитектура

### 4.1 Загрузка и глобалы
- `metadata.xml` — `<directory>tboiac</directory>`, версия. Мод кладётся в `mods/tboiac`.
- `main.lua` — `RegisterMod("TBOIAC", 1)`, создаёт **единственный глобал `TBOIAC`** (в коде `local AC =
  TBOIAC`). Модули грузятся через `include("scripts.tboiac....")` (не `require`: `include` корректно
  перезагружается `luamod`). Порядок загрузки важен (см. `main.lua`): util → data → i18n → names →
  save → input → render → menu → catalog → grid → icons → registry → imgui → rules (params, engine,
  events, conditions, actions, effects, presets, editor) → features → вкладки → `registry.start()`.
- `AC.hasRepentogon = REPENTOGON ~= nil`. Любой код с REPENTOGON-API обязан проверять это
  (и не читать глобалы вроде `ImGui`/`EntityConfig`, если его нет — smoke-тест ловит чтение
  несуществующих глобалов).

### 4.2 Реестр фич (`core/registry.lua`)
Фича — таблица `{ id, label?, pages = { [id] = page }, callbacks = { {ModCallbacks.X, fn, param?} },
init?(), reset?() }`. `registry.register` регистрирует страницы; `registry.start()` вешает колбэки,
каждый обёрнут в `pcall` (ошибка логируется `[TBOIAC] error in <id>`). `reset()` вызывается кнопкой
паники. Фичи без `label` не показываются в корневом списке (например `pools`, `drops`, `quick`,
`icons`), но их страницы доступны по ссылкам. Ядро регистрирует: `MC_POST_RENDER` (меню, тосты,
отложенное сохранение, ImGui), `MC_INPUT_ACTION` (блокировка ввода), `MC_POST_UPDATE`
(`menu.runQueue()` — выполнение действий меню), `MC_POST_GAME_STARTED` (загрузка сохранения),
`MC_PRE_GAME_EXIT` (запись).

### 4.3 Меню (`core/menu.lua`, ~970 строк) — сердце UI
- **Вкладки** (`AC.menu.tabs` задаются в `main.lua`): Быстро, Игрок, Предметы, Враги, Мир, Правила,
  Студия, Настройки. Переключение: Q/E (кроме сеток), Tab/Shift+Tab, LB/RB, клик.
- **Страница**: `{ title, build = fn() -> items, layout = "list"|"tiles", icon?, side?, live? }` или
  сетка из `core/grid.lua`. `layout = "tiles"` — большие кнопки 2 колонки (главные страницы вкладок).
  `side = fn(x, y, w) -> height` — боковая панель (схема правила). У пункта может быть свой `side`.
- **Пункты**: `action`, `toggle`, `number`, `choice`, `page`, `text`, `info`; опционально `icon`
  (спецификация иконки, §4.8), `desc` (пояснение внизу), `side`.
- **Иконки строк**: `ENTRY_ICONS` в `menu.lua` — карта *ключ перевода подписи → id предмета*
  (иконки подобраны по номерам ванильных предметов **по памяти**, могут быть неточны). Если своей
  иконки нет — рисуется иконка страницы (наследуется от пункта-ссылки), приглушённая. Ключ находится
  обратным поиском `AC.i18n.keyFor(labelText)` — поэтому страницы не надо править ради иконок.
- **Пояснения**: `AC.i18n.desc(label)` ищет ключ `<ключ>_d` в словарях. Чтобы добавить пояснение
  пункту — достаточно добавить `<key>_d` в оба `lang`-файла.
- **Мышь**: во время отрисовки регистрируются хит-зоны (`hit(x,y,w,h,{hover,click,rclick})`), в
  `menu.update` — наведение/клики по ним. Координаты мыши: `Isaac.WorldToScreen(Input.GetMousePosition(true))`.
  Курсор рисуется модом (`drawCursor`).
- **Esc**: пока меню открыто — закрывает меню (стек страниц сохраняется, повторное открытие — туда
  же). Пауза игры (`ACTION_PAUSE`/`ACTION_MENUBACK`) блокируется, пока меню открыто, и ещё 20
  кадров после закрытия (`input.pauseGrace`). Пока игра на паузе (`Game():IsPaused()`) меню мода
  скрыто и не обрабатывает ввод.
- **Отложенные действия**: `menu.defer(fn, ...)` → очередь → `menu.runQueue()` в `MC_POST_UPDATE`.
  Все `action` и выборы в сетках идут через очередь. Тоглы/числа меняются сразу (это просто данные).
- **Режим «поставить мышкой»** (`menu.startPlace`): меню скрывается, иконка на курсоре, ЛКМ →
  `entry.place(worldPos, amount)` (через очередь), ПКМ/Esc → назад в меню.
- **Центр**: панель по центру экрана + `ui.offX/offY` из настроек. `ui.layout` — версия раскладки для
  миграции сохранений (сейчас 3; при изменении раскладки увеличить — старые позиции сбросятся).

### 4.4 Сетки (`core/grid.lua`)
`grid.page{ title, entries, pickHint, altHint, chips, filter, sorts, amount, discover, dynamic, extra }`.
Запись: `{ name, alias?, id?, desc, icon, pick(alt, amount), place(worldPos, amount)? }`.
Поиск — просто печатать (буквы идут в поиск, поэтому Q/E на сетках не переключают вкладки).
Фильтры-«чипы» над сеткой: стрелка вверх из первого ряда или клик; Enter/ЛКМ — следующее значение,
Shift+Enter/ПКМ — предыдущее. Встроенные чипы: сортировка (если `sorts`), количество (если `amount`).
У каждой сетки есть запасной `build` (список) — его использует ImGui и тест.
Сетки: `items_grid` (тир, тип, пул, сорт, кол-во), `trinkets_grid`, `boss_grid`, `enemy_grid`
(чемпион, кол-во, сорт), `pickups_grid` (кол-во).

### 4.5 Ввод (`core/input.lua`)
- Фронты нажатий считаются **вручную** (`edge()`), т.к. `Input.IsButtonTriggered` привязан к 30 Гц
  тику и в `POST_RENDER` (60 Гц) срабатывает дважды.
- Своя **раскладка**: `input.layout = "en"|"ru"`, ЙЦУКЕН на тех же физических клавишах;
  переключение Alt+Shift, Ctrl+Shift или клик по `[EN]/[RU]`. Игра не отдаёт текст — только коды клавиш.
- `input.typed()` (символы кадра), `input.escape()`, `input.tabKeys()` (E/Q), `input.mouse()`,
  `input.poll()` (стрелки с автоповтором, confirm, alt = Shift+Enter/X, back, tabNext/Prev).
- `input.onInputAction` блокирует игровые действия (движение, стрельба, бомба, предмет, карта, дроп,
  карта уровня, рестарт, пауза) пока открыто меню или идёт размещение.

### 4.6 Рендер (`core/render.lua`)
Шрифт — первый загрузившийся из `FONT_CANDIDATES` (`font/cjk/lanapixel.fnt` первым —
**подтверждено скриншотами: кириллица рендерится**). Прямоугольники — спрайт 1×1 `box.anm2`.
`render.text(s, x, y, color, scale)`, `render.wrap`, `render.toast` (подавляется в «чистом кадре»).

### 4.7 Сохранение (`core/save.lua`)
JSON в `save1.dat` мода (`mod:SaveData`). `save.defaults` — все секции: `ui, keys, player, time,
enemies, world, recent, rules, pools, waves, studio, profiles, iconCache, drops, run`. При загрузке
недостающие ключи дополняются из defaults (`util.merge`). Запись **отложенная**: `save.markDirty()` +
`save.flush()` не чаще раза в секунду, плюс при закрытии меню/выходе. **Никогда не хранить
разреженные массивы** (дыры в списках ломают JSON) — используйте строковые ключи (`"s3"`, `"r12"`).
`run` — состояние забега (флаги, счётчики, срабатывания, бонусы статов), сбрасывается на новом забеге.

### 4.8 Иконки и спрайты (`core/icons.lua`)
- Спецификация иконки: число (id предмета) | `{ trinket = id }` | `{ entity = "t.v", t, v }` | функция.
- Предметы/брелоки: png из `ItemConfig.GfxFileName` на своём `resources/gfx/tboiac/ui/icon.anm2`
  (кадр 32×32 с опорной точкой в центре) — работает на чистой игре.
- Мобы/боссы/пикапы: путь anm2 берётся (1) из REPENTOGON `EntityConfig.GetEntity(t,v):GetAnm2Path()`,
  (2) из `save.data.iconCache` — мод **запоминает** anm2 каждой встреченной сущности
  (`Sprite:GetFilename()`), (3) **активное обнаружение** при открытии сетки: по одной сущности за
  тик спавнит её в (-3000,-3000), читает anm2 и сразу удаляет всё, что появилось. Боссы из `UNSAFE`
  (274, 275, 406, 407, 412, 912, 950, 951) так не спавнятся. Нет спрайта → инициалы в ячейке.

### 4.9 Правила (`scripts/tboiac/rules/`)
- `engine.lua`: правило `{ id, name, enabled, scope("always"|"run"|"chapter"), chapter,
  event{id,p}, filter{mode,t,v,s,name}, logic("and"|"or"), conds[{id,p,neg}], acts[{id,p,delay}] }`.
  `engine.defineEvent/Condition/Action({ id, label, params, entity?, match?/check?/run? })`.
  `emit(eventId, ctx)` → для каждого правила: сцена/фильтр → условия → действия (с задержками через
  очередь). Защита от циклов: `MAX_FIRES_PER_FRAME = 200`, `MAX_DEPTH = 6`. Метки (`setLabel`),
  списки (`addToList`), флаги/счётчики (`engine.flag/counter`). `ctx.stop` — прервать цепочку.
- `params.lua`: спецификации параметров (`P.number/choice/toggle/text/catalog/entity`), общие списки
  (цели `P.TARGETS`, формации, сиды, музыка, клавиши…). Редактор строит UI из спецификаций сам.
- `events.lua` (18 событий + колбэки), `conditions.lua` (26), `actions.lua` (действия + общие
  `entityAction/targets/position`), `effects.lua` (движение, вид, двери, сиды, музыка, текст на экране),
  `presets.lua` (20 пресетов; имена/тексты переводятся при загрузке), `editor.lua` (страницы
  редактора + **схема правила** `drawRuleDiagram` в боковой панели).
- Дополнительно события/условия/действия определяют `features/waves.lua` (волны) и
  `features/studio.lua` (manual, run_rule, toggle_option, stopwatch, stop_scenarios).
- Сущности, заспавненные правилами, помечаются `tboiacByRule` — событие «появился враг» на них не
  срабатывает (иначе бесконечные цепочки).

### 4.10 Фичи (`scripts/tboiac/features/`)
`quick` (вкладка «Быстро», плитки), `player`, `items` (сетки, пулы-фильтр `poolSet`, рероллы),
`pools` (фильтры пулов через `MC_POST_GET_COLLECTIBLE`; не мешает выборке при `AC.poolSampling`),
`pickups`, `drops` (награды через `MC_PRE_SPAWN_CLEAN_AWARD`), `time` (замедление, **заморозка**:
флаг/позиция/кадр анимации каждый тик + пропуск ИИ в `MC_PRE_NPC_UPDATE`), `enemies`, `waves`,
`world` (телепорты, этажи, карта, проклятья, комната, изи-сиды, музыка, HUD, консоль), `studio`
(сценарии, горячие клавиши, оверлей, чистый кадр, профили; экспортирует `AC.studio.setClean`),
`settings`.

### 4.11 REPENTOGON (`core/imgui.lua`, `core/names.lua`)
- ImGui-окно зеркалит **те же страницы** (консоль `~` → TBOIAC → Меню). Внутри ImGui-колбэков
  `menu.push/pop` перенаправлены на стек ImGui (важно: вызывать `AC.menu.pop()` внутри функции,
  а не передавать `AC.menu.pop` ссылкой — был баг). Пока ImGui активен, горячие клавиши мода не
  срабатывают.
- Названия: `Isaac.GetString(category, key)` (категории `Items`, `PocketItems`, `Entities`,
  `Players`), `EntityConfig`. Пулы: `ItemPool:GetCollectiblesFromPool(pool)` → `{ itemID, … }`.
- Документация REPENTOGON: публичный репозиторий `TeamREPENTOGON/REPENTOGON`, папка `docs/docs`
  (`ImGui.md`, `ItemPool.md`, `EntityConfigEntity.md`, `Isaac.md`, `xml/stringtable.md`). Сайт
  repentogon.com и steamcommunity.com в этой среде заблокированы, GitHub доступен (клон через git).

## 7. Тестирование: `tools/smoke.lua`

- Загружает мод на **заглушках API**: строгие enum'ы (обращение к несуществующему имени → FAIL),
  `strictObj` для игрока (метод не из `PLAYER_API` → FAIL) и двери, `obj()` для прочего (любой метод).
- После загрузки ставит защиту `_G`: чтение/создание неизвестного глобала → FAIL.
- `frame(keys)` — один кадр рендера с нажатыми клавишами + `menu.runQueue()`.
- Проверяет: обход **всех** страниц меню на RU и EN с нажатием каждого элемента; каждое событие,
  условие и действие правил **со всеми вариантами** choice/toggle-параметров; защиту от циклов;
  пулы, метки, списки, стоп; поведения движения, текст на экране; волны (полный прогон и таймер);
  награды; студию (профили через JSON, секундомер, чистый кадр, toggle_option, run_rule);
  регрессию заморозки; вкладки и сетки (навигация, Enter/Shift+Enter, печать, Backspace);
  Esc/повторное открытие, игнор ввода на паузе, клики мышью (X, плитка), размещение мышкой,
  русскую раскладку, чипы, обнаружение спрайтов, отложенные действия; симуляцию REPENTOGON
  (имена, ImGui: 300+ страниц кликами, нет дублей id элементов).
- Ошибки в логе (`error`/`failed`) и тосты «Ошибка» → FAIL.
- Новая фича ⇒ добавить в тест её прямую проверку и нужные заглушки (enum-значения, методы).
- Тест ловит ошибки Lua, **но не поведение игры** (раскладку экрана, реакцию ИИ, реальные сигнатуры).

## 8. Подводные камни (обязательно помнить)

- **Не вызывать игровые действия в `MC_POST_RENDER`** (пилюли/карты/предметы) → `menu.defer`.
- `IsButtonTriggered` в render срабатывает дважды → свои фронты (`input.edge`).
- **`cond and f() or x`** в Lua вернёт `x`, если `f()` вернул `nil`/`false` (был баг с описаниями).
- JSON: **никаких разреженных массивов** (ключи-строки).
- Заморозка врагов: попадание снимает `FLAG_FREEZE` — переустанавливать каждый тик + `MC_PRE_NPC_UPDATE`
  → `return true` пропускает ИИ.
- Статусы на боссах в Rep имеют «кулдаун» — не полагаться на `AddFreeze` для постоянной заморозки.
- Буквы в сетках идут в поиск — горячие клавиши-буквы (Q/E) там не работают; вкладки через Tab/мышь.
- Внутри ImGui-колбэков `menu.push/pop` подменены — вызывать через функцию-обёртку.
- Пока открыт ImGui (REPENTOGON), игнорировать горячие клавиши мода (`AC.imgui.active()`).
- Поиск по кириллице: `AC.names.lower` (обычный `string.lower` не понижает кириллицу).
- Для всех новых сущностей, заспавненных правилами, ставить `AC.ruleEvents.markSpawned(e)`.
- Экран Isaac в логических пикселях ~480×270: панель ~288 px ширины, не больше ~9 строк/5 рядов плиток.

## 12. Рецепты

- **Новое действие правила**: `engine.defineAction({ id, label = "a_x", params = { P.number(...) },
  run = function(p, ctx, rule) ... end })` в `rules/actions.lua` или `rules/effects.lua`; для действий
  над сущностями — `entityAction(id, label, params, fn(e, p, ctx))` (получит выбор цели).
  Добавить `a_x` (+ `a_x_d` при желании) в оба `lang`. Тест подхватит автоматически (все варианты).
- **Новое событие**: `engine.defineEvent{ id, label, params, entity?, match? }` + где-то
  `engine.emit(id, { entity, player, value })` из колбэка игры (в `events.callbacks`).
- **Новое условие**: `engine.defineCondition{ id, label, params, check = function(p, ctx, rule) }`.
- **Новая страница**: в фиче `pages = { my_page = { title = fn, build = fn, layout? } }`, ссылка —
  `menu.link(t("m_my"), "my_page")`. Иконка — добавить `m_my = <id>` в `ENTRY_ICONS`.
- **Новая сетка**: `AC.grid.page{ ... }` (см. §4.4); `pick`/`place` вызываются из очереди.
- **Новая настройка**: поле в `save.defaults`, виджет `menu.toggle/number/choice(label, "section", key)`.
- **Перевод**: ключ в `lang/ru.lua` и `lang/en.lua` одновременно (тест сравнит наборы).
