# Разбор Da Rules (v0.9840, workshop 2403871374) и что берём в TBOIAC

Архив прислан автором (JSG). Код Da Rules **не хранится в этом репозитории** и не используется:
здесь только описание его механик своими словами и план их собственной реализации (см. раздел 5).

## 2. Модель правила Da Rules

```
Правило = Источник  →  Цель   [+ Условие] [+ Модификатор] [+ режим этажей]
```

- **Источник** — *что/когда*: сущность (тип.вариант.подтип), группа («все мобы», «все предметы»,
  «все боссы текущей главы», «все пикапы», «все грид-объекты») или событие («спешл»).
- **Цель** — *во что превращается / что происходит*: другая сущность (замена «каждый X — это Y»)
  или спешл-действие.
- **Условие** (одно на правило): шанс %, N-е совпадение, один раз за забег, один раз на
  сущность, есть/нет метки, каждые X с, через X с, скорость больше X, дистанция до игрока,
  у игрока есть предмет/брелок, персонаж, нажата кнопка/клавиша, значение счётчика,
  «светофоры» (красный/зелёный/синий — глобальные флаги-переключатели).
- **Модификатор** (один на правило): повторить X раз, толкнуть, поставить в позицию, у игрока,
  в случайном месте, обездвижить, прилипнуть к ближайшему, стрельба в 4/8 направлений или в
  сторону игрока, клоны в своей формации, повесить метку, умереть через X с, покрасить.
- **Режим этажей**: только этот забег / каждый этаж / конкретная глава.

Правила хранятся строкой в `save1.dat` (свой текстовый формат), есть пресеты, импорт из консоли,
экспорт в отдельный челлендж-мод.

### Типы событий (источников-спешлов)
Смерть, смерть/воскрешение игрока, телепорт, эффект (+исчезновение), слеза/снаряд (+попадание),
урон, подбор предмета/пикапа/брелока, использование активки, бомбы игрока, новый этаж/глава,
зачистка комнаты, вход в комнату (новая/посещённая/обычная/дьявола/ангела/аркада/испытание),
ходьба, клик мыши, клавиша, кнопка геймпада, таймер, апдейт каждой сущности по типам,
направление стрельбы, количество ресурсов (монеты/бомбы/ключи/HP/пикапы/заряд/предметы > или < X),
счётчики, старт забега, лазеры (Tech/Brimstone/Pride/Holy), столкновения игрока.

### Действия (спешлы-цели), около 340 штук, сгруппированы
- **Спавн/замена** любой сущности, клоны в формации, списки сущностей (добавить/очистить/убрать).
- **Движение**: толкнуть, множитель скорости, притяжение/отталкивание, орбита, следование по
  пути (абсолютному/относительному), «управляется как Робо-бэби 2.0», телепорт в позицию,
  к игроку, в случайное место, «Get over here!» (игрока к объекту).
- **Вид**: размер, поворот, цвет/прозрачность, костюмы, маскировка под другую сущность,
  проигрывание анимаций, покраска стен/пола, смена декораций комнаты, текст (как у правил,
  у сущности, затухающий, в HUD, как у предмета, как у гадального автомата).
- **Бой**: урон себе/ближайшему/всем в радиусе, лечение, убить, чемпион/снять чемпиона,
  свойства (EntityFlags) добавить/убрать, коллизии с сущностями и сеткой.
- **Игрок**: статы, дать/отнять предмет, брелок, карту, монеты/бомбы/ключи, заряд активки,
  сменить персонажа, убить игрока, использовать случайное всё.
- **Мир**: двери (закрыть/открыть/баррикада/проклясть/запереть/убрать, аркадные, бомбовые),
  переход в комнату любого типа, замена текущей комнаты, сид-эффекты (изи-сиды), проклятья,
  звук, музыка, консольная команда, «светофоры», счётчики, остановка цепочки правил, задержка.

### Интерфейс и сервис
Мышь, окна-спрайты, поиск, режим «CMD» (ввод ID вручную), «Bonus Spawner» вне стартовой комнаты,
подсказки, undo/redo, автосохранение, пресеты, скрытие HUD, защита от зацикливания, поддержка
модов (Revelations, FiendFolio, Deliverance, Retribution), челленджи «Rules Playground» и
«Rules Disabled» (аварийное отключение правил). Около 25 консольных команд (`saferules`,
`loadcmdrules`, `importpresetrules`, `disablerules` и т.д.).

## 3. Сравнение с TBOIAC

| Область | Da Rules | TBOIAC v0.1 |
|---|---|---|
| Управление | мышь + клавиатура, геймпад не поддерживается | клавиатура + **геймпад** |
| Язык | английский, текст частично нарисован спрайтами | **RU/EN**, весь текст в словарях |
| Прямые инструменты (без правил) | Bonus Spawner (спавн + несколько спешлов) | игрок, предметы, пикапы, время, мобы, телепорты, этажи, проклятья |
| Движок правил | **очень богатый** (≈60 событий, ≈340 действий, 18 условий, 18 модификаторов) | нет (фаза 2) |
| Замены «каждый X — это Y» | да | нет |
| Сид-эффекты, светофоры, счётчики, метки, списки | да | нет |
| Иконки сущностей в меню | да (anm2-кэш) | нет |
| Модовые сущности | 4 мода вручную | нет |
| Сохранение | свой строковый формат | JSON |
| Архитектура | один глобальный монолит | модули и реестр, smoke-тест |

Вывод: у TBOIAC сильнее прямые инструменты, геймпад, локализация и сопровождаемость. Главное,
чего не хватает, — движок правил. В Da Rules это основная ценность мода.

## 4. Как переносить

**Рекомендация: не форкать Da Rules, а перенести его модель правил в архитектуру TBOIAC.**
Причины: 225 тыс. строк связанного глобального кода, завязка на мышь и спрайтовые окна,
отсутствие геймпада и локализации, прямая просьба автора не строить моды на его коде.

Движок правил TBOIAC (фаза 2) будет совместим по смыслу с Da Rules и шире его:

1. **Источник** — событие + фильтр сущности (тип/вариант/подтип или группа), как в Da Rules.
2. **Условия** — список, а не одно условие; логика И/ИЛИ/НЕ. Набор условий как у Da Rules плюс
   этаж, тип комнаты, HP, предметы.
3. **Цель/действия** — список действий по порядку, с задержками; сначала около 40 ключевых
   действий из групп выше, затем расширение по группам.
4. **Модификаторы** — как параметры действия (кол-во, позиция, формация, время жизни, цвет).
5. Метки, счётчики, светофоры (у нас — именованные переменные/флаги), списки сущностей.
6. Режим этажей и пресеты.
7. Аварийное отключение правил (горячая клавиша + челлендж «Rules Disabled»), защита от
   зацикливания (лимит срабатываний за кадр).

## 5. Решение

Код и таблицы данных Da Rules **не используются**. Его механики реализуются в TBOIAC заново, своим
кодом, на основе общих знаний API игры. Импорт формата правил Da Rules не делаем.
