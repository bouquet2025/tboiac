# TBOIAC — Isaac Admin Console: план мода

Цель: sandbox-меню для **The Binding of Isaac: Repentance+**, в котором контент-мейкер может
управлять игрой целиком — предметы, пикапы, игрок, мобы, боссы, время, локации, правила — без
консоли и без знания ID.

Идейная основа — мод **Da Rules** (JSG, Steam Workshop 2403871374): внутриигровое меню-песочница.
Подробный разбор его устройства и план переноса: [DA_RULES_ANALYSIS.md](DA_RULES_ANALYSIS.md).
Код Da Rules в репозиторий **не копируется** (он принадлежит автору; условия — в разборе, раздел 5);
мы пишем свою реализацию с расширенным функционалом и собственной архитектурой.

---

## 1. Принципы

1. **Работает на ванильном API REP+.** REPENTOGON — опциональное расширение (если установлен,
   открываются дополнительные функции: ImGui-меню, локализованные названия, новые колбэки).
2. **Всё из меню.** Любое действие доступно без консоли; консольные команды (`Isaac.ExecuteCommand`)
   используются только там, где у API нет аналога (варп по этажам, `goto` комнат).
3. **Модульность.** Каждая фича — отдельный модуль, который регистрирует свои страницы меню и
   колбэки через реестр. Новые фичи добавляются без правки ядра.
4. **Всё сохраняется.** Настройки, тогглы, правила, пресеты — в `save1.dat` мода (JSON).
5. **Безопасность для записи.** Меню не ломает забег: ввод игрока блокируется, пока меню открыто;
   есть «паника»-кнопка, сбрасывающая все модификаторы.

## 2. Полный функционал

### 2.1 Меню и управление
- Открытие: **F2** (клавиатура) / **Select + Y** (геймпад), переназначаемо.
- Навигация стрелками / D-pad, **Enter**/A — выбрать, **Backspace**/B — назад, ←/→ — менять значение,
  зажатие — автоповтор, **Shift** — шаг x10.
- Виджеты: кнопка, переключатель, число, выбор из списка, подстраница, ввод текста (поиск).
- Поиск по названию предметов/брелоков/мобов с клавиатуры.
- Избранное и «недавние» (последние выданные предметы/мобы).
- Всплывающие уведомления (тосты) о выполненных действиях.
- Настройки UI: язык (RU/EN), масштаб, прозрачность, позиция, «пауза мира при открытом меню».
- **Кнопка паники** — сбросить все активные модификаторы.

### 2.2 Игрок
- Выбор цели: все игроки / P1…P4 (кооп), включая Jacob & Esau, Tainted Forgotten.
- Бессмертие, «одно попадание — смерть», бесконечные HP.
- Статы: урон, скорострельность, скорость, дальность, скорость слёз, удача — как бонус и как
  жёсткая фиксация значения.
- Полёт, проход сквозь стены (noclip), невидимость для мобов, размер персонажа.
- Здоровье: красные/душевные/чёрные/костяные/золотые/вечные/гнилые/сломанные сердца,
  контейнеры, полное лечение, установка точного значения.
- Ресурсы: монеты/бомбы/ключи — установить, бесконечные, золотые бомба/ключ.
- Смена персонажа (включая Tainted), воскрешение, убить игрока.
- Бесконечный заряд активки, мгновенная перезарядка.

### 2.3 Предметы и пикапы
- Выдать предмет по ID / поиску, как пьедестал или сразу в инвентарь; убрать; убрать все.
- Брелоки: выдать, поглотить (smelt), убрать. Карты/руны/пилюли: заспавнить или использовать.
- Спавн любого пикапа (сердца, монеты, бомбы, ключи, сундуки, батарейки, мешки…).
- Рероллы: пьедесталы в комнате, инвентарь (D4), пикапы.
- **Пулы**: чёрный/белый список предметов, замена предмета X на Y, «только предметы качества N»,
  «один и тот же предмет везде», кастомный пул для конкретного типа комнаты.
- Правила выпадения: множители наград за комнату, гарантированные сундуки, отключение пикапов.

### 2.4 Время
- Замедление / ускорение мира (эффект сломанных часов), в т.ч. постоянное.
- Заморозка мобов, снарядов, всего мира («стоп-кадр» для записи).
- Покадровый шаг (при остановленном мире).
- Управление игровым таймером (сброс, фиксация) — для челленджей на время.
- Таймеры/отсчёты на экране для видео.

### 2.5 Мобы и боссы
- Спавн любой сущности по `тип.вариант.подтип`, количество, позиция (у игрока/центр/курсор).
- Каталог боссов и популярных мобов, поиск по названию.
- Чемпионы: сделать чемпионом (цвет), все мобы — чемпионы.
- Дружественный спавн (очарованные союзники).
- Убить/удалить всех, очаровать всех, заморозить всех.
- Множители HP/скорости/урона мобов, «мобы исцеляются», «мобы размножаются при смерти».
- Замена: «все мобы → X», «все боссы → Y», рандомизатор мобов.
- Волны: сценарий спавна по таймеру (арены/челленджи).

### 2.6 Локации и телепорты
- Телепорт в любую комнату текущего этажа и в спецкомнаты (сокровищница, магазин, босс,
  секретка, супер-секретка, дьявол/ангел, I AM ERROR, чёрный рынок, стартовая…).
- Варп на любой этаж и альтернативный путь (Basement…Home, Downpour/Mines/Mausoleum/Corpse…).
- Загрузка конкретной планировки (`goto s.boss.XXXX` и т.п.).
- Карта: раскрыть всё, компас/синяя карта; проклятья — вкл/выкл каждое, блокировать все.
- Комната: зачистить, открыть все двери, спавн люка/лаза/ящика/пьедестала, рестарт комнаты.
- Грид-объекты: камни, ямы, шипы, блоки — спавн и очистка.
- Рестарт забега, сид, выбор персонажа.

### 2.7 Движок правил (сердце мода)
Правило = **Триггер → Условия → Действия**, редактируется из меню, сохраняется, включается/
выключается, объединяется в пресеты («Каждая комната — случайный босс», «Урон удваивается за
каждый предмет» и т.д.).
- **Триггеры:** вход в комнату, зачистка, новый этаж, получение урона, нанесение урона, убийство
  моба/босса, подбор предмета/пикапа, использование активки/карты/пилюли, выстрел, каждые N
  секунд, старт забега, смерть, покупка, взрыв бомбы…
- **Условия:** шанс %, тип комнаты, этаж, персонаж, есть/нет предмета, HP меньше/больше,
  счётчик/переменная, сколько раз уже сработало, кулдаун, логика И/ИЛИ/НЕ.
- **Действия:** выдать/убрать предмет, спавн моба/пикапа, урон/лечение, изменить стат,
  телепорт, варп, замедлить/заморозить время, реролл, проклятье, показать текст, звук,
  изменить переменную, выполнить консольную команду, запустить другое правило.
- Переменные и счётчики правил (выводятся на экран).

**Паритет с Da Rules** (см. разбор): замены «каждый X — это Y» для мобов/предметов/пикапов/
грид-объектов; группы источников («все мобы», «все боссы главы», «все пикапы»…); метки на
сущностях; флаги-«светофоры»; списки сущностей; режим этажей (этот забег / каждый этаж / глава);
действия движения (толчок, притяжение, орбита, путь), вида (размер, поворот, цвет, костюмы,
маскировка, анимации), дверей, сид-эффектов, музыки/звука, текста; условия «N-е совпадение»,
«раз на сущность», «был в комнате при входе», дистанция, скорость; модификаторы-формации;
аварийное отключение правил и защита от зацикливания.

### 2.8 Инструменты контент-мейкера
- Профили/пресеты: сохранить и загрузить весь набор настроек и правил (несколько слотов).
- Горячие клавиши на любые действия (макросы), в т.ч. последовательности.
- Сценарии: список действий с задержками (постановка сцен для роликов).
- Оверлей: счётчики, таймер, название активных правил, кастомный текст; скрыть HUD.
- «Чистый кадр»: спрятать меню и тосты одной кнопкой.
- Логирование действий (для монтажа).

### 2.9 REPENTOGON (опционально)
- Меню на ImGui (мышь, поиск, вкладки) как альтернатива встроенному.
- Локализованные названия предметов/мобов, иконки.
- Доп. колбэки для правил (pre-add collectible, pre-level-select и др.).

## 3. Архитектура

```
metadata.xml
main.lua                      — регистрация мода, загрузка модулей
scripts/tboiac/
  core/
    util.lua                  — утилиты, логгер, перебор игроков/сущностей
    i18n.lua, lang/ru.lua, lang/en.lua
    save.lua                  — JSON-сохранение настроек
    input.lua                 — клавиатура/геймпад, блокировка ввода, текстовый ввод
    render.lua                — шрифт, подложки, тосты
    menu.lua                  — стек страниц, виджеты, навигация
    registry.lua              — регистрация фич, страниц и колбэков
  features/
    player.lua  items.lua  pickups.lua  time.lua  enemies.lua  world.lua  settings.lua
    rules/ (фаза 2)
resources/gfx/tboiac/ui/      — спрайт подложки меню
tools/                        — проверка синтаксиса и smoke-тест на заглушках API
```

Фича — таблица `{ id, init(AC), pages = {...}, callbacks = {...}, reset() }`. Ядро вызывает
`reset()` у всех фич по «кнопке паники».

## 5. Открытые вопросы
- Поддержка кириллицы шрифтом: ванильные шрифты могут не содержать кириллицу — нужна проверка
  в игре; при проблеме язык переключается на EN (Настройки → Язык) или добавляем свой шрифт.
- Использование `Isaac.ExecuteCommand` может влиять на достижения в забеге — предупреждаем в UI.
